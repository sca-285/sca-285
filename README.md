# Hey, I'm Sca285 👋

I'm an enthusiast of AI image generation who likes tinkering with **Stable Diffusion WebUI Forge**, **reForge**, **ComfyUI** and related projects. I make small extensions and utilities to improve my own workflow, then share them in case they might be useful to someone else.

Outside GitHub, I'm also a [creator on Civitai](https://civitai.red/user/sca285), where I share AI-generated images and experiment with models and LoRAs. It's another place for me to explore visual ideas, learn by trying things out, and exchange inspiration with the community.

I'm not a professional developer. I often work with AI coding assistants to turn ideas into working extensions, figure out bugs, and learn as I go. The projects here are personal experiments: some parts may be rough around the edges, and things won't always work perfectly. I'm still learning, so kind feedback and bug reports are appreciated.

## Things I've been tinkering with

| Project | A little about it |
| --- | --- |
| [**Prompt Vault**](https://github.com/sca-285/sd-webui-prompt-vault) | A place to organize tags and prompts, keep prompt history, and use local tools for captioning and image tagging. |
| [**Kitchen Samplers**](https://github.com/sca-285/sd-kitchen-samplers) | Extra samplers and schedule types for Forge-family WebUIs. |
| [**Optical Realism**](https://github.com/sca-285/sd-forge-optical-realism) | Experiments with photographic effects such as lens character, depth of field, haze, and light scatter. |
| [**Auto Color Corrector**](https://github.com/sca-285/sd-forge-auto-color-corrector) | A small set of tools for tweaking color casts and contrast in generated images. |
| [**Digital Mastering**](https://github.com/sca-285/sd-webui-digital-mastering) | Post-processing ideas for the final stages of an image-generation workflow. |
| [**Forge Notebook**](https://github.com/sca-285/sd-forge-notebook) | A lightweight notebook for jotting things down inside a Forge-family interface. |
| [**Lobe Theme Redux**](https://github.com/sca-285/sd-webui-lobe-theme-redux) | An attempt to customize the look and feel of the WebUI workspace. |
